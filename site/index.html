Getting started

All downloads ↗
Download a release archive using the link above.

Put the binary on your PATH, then run:

tb devices
tb test login.yaml
tb test flows/ -p web --headless
login.yamlYAML reference ↗
appId: com.example.app
---
- launchApp
- tapOn: "Email"
- inputText: "hello@example.com"
- tapOn: "Continue"
- assertVisible: "Welcome"

Requires adb for Android; macOS + Xcode for iOS simulators; Chrome for web. Setup details ↗

AI agents

Guide ↗

Screen text with element refs, change summaries, JSON results, and flow recording. Use from a shell; tb mcp is optional.

tb look
tb do 'tapOn: @3'
tb save --preview flow.yaml --json
tb save flow.yaml
tb replay flow.yaml -d DEVICE --json

Replay requires a recorded launchApp first. Close the interactive session with tb close before replaying.

Claude Code plugin + portable skills
claude plugin marketplace add Elforama/testbuddy
claude plugin install test-buddy@test-buddy

The plugin bundles the CLI for macOS ARM64. On other hosts, install the CLI separately. The portable skill includes CLI, YAML, and debugging docs for Codex, Gemini, Cursor, and other shell-capable agents. Run tb agent-guide for a quick reference.

Multi-device flows

Reference ↗

Assign device roles, run steps in parallel, share values, and synchronize with signal / waitForSignal.

devices:
  alice: { platform: ios, appId: com.example.chat }
  bob: { platform: android, appId: com.example.chat }
---
- parallel:
    alice: [launchApp]
    bob: [launchApp]
- alice:
    - tapOn: "Send"
    - signal: sent
- bob:
    - waitForSignal: sent
    - assertVisible: "Message received"

Example app with a prepared message. Run with tb test chat.yaml. Android, iOS, and web roles can mix.
