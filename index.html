Why Test Buddy

Everything you need. Nothing you don't.

  • Fast by default

    Each step runs the moment your app is ready. No fixed waits, no guessing.

  • Bring your Maestro flows

    Already have Maestro YAML? Run it as is with tb test.

  • Android, iOS and web

    One tool for emulators, iOS simulators and Chrome. Native apps and Flutter both work.

  • Made for AI agents

    Agents can look at the screen, tap around and save what they did as a test.

  • Many devices, one test

    Test a chat between an iPhone and an Android phone in a single flow.

Get started

Up and running in a minute.

  1. 1

    Install

    Pick your system above.

    Then put tb on your PATH. You'll need adb for Android, Xcode for iOS, or Chrome for web.

  2. 2

    Find a device

    Terminal
    $ tb devices
  3. 3

    Run your test

    Terminal
    $ tb test login.yaml

AI agents

Let your agent write the tests.

Your coding agent explores the app, then saves the steps as a test you can run again.

Terminal
$ tb look              # what's on screen?
$ tb do 'tapOn: @3'    # tap something
$ tb save flow.yaml    # keep it as a test
Add to Claude Code
$ claude plugin marketplace add Elforama/testbuddy
$ claude plugin install test-buddy@test-buddy

Multi-device

Two phones. One test.

Give each device a name, then tell it what to do.

chat.yaml
devices:
  alice: { platform: ios, appId: com.example.chat }
  bob: { platform: android, appId: com.example.chat }
---
- parallel:
    alice: [launchApp]
    bob: [launchApp]
- alice:
    - tapOn: "Send"
    - signal: sent
- bob:
    - waitForSignal: sent
    - assertVisible: "Message received"
